# PRODIGY_SD_03

## Contact Management System

### Description

This project is developed as **Task 3** of the **Prodigy InfoTech Software Development Internship**.

The application allows users to manage contacts using a menu-driven interface.

---

## Features

- Add Contact
- View Contacts
- Search Contact
- Edit Contact
- Delete Contact
- Menu Driven Interface

---

## Technologies Used

- Java
- VS Code
- JDK 24

---

## How to Run

Compile:

```bash
javac Main.java
```

Run:

```bash
java Main
```
